# 第 1 章 · 全栈开发概述与环境准备

对应笔记：`1.1 什么是全栈开发` / `1.2 前后端职责与协作方式` / `1.3 技术栈选型：前端、后端、数据库怎么选` / `1.4 开发环境搭建` / `1.5 第一个全栈项目结构预览`

## 文件对照

| 笔记 | 文件 | 内容 |
|---|---|---|
| 1.1 | `01-request-flow.html` | 请求完整链路、每一环的职责与故障表现、SSR 与前后端分离对比、能力模型 |
| 1.2 | `02-roles.html` | 三层职责边界、接口约定示例（请求/响应）、数据流方向、联调常见问题 |
| 1.3 | `03-stack.html` | 前端 / 后端 / 数据库方案对比表、选型理由与局限、四条判断标准 |
| 1.4 | `04-env.html` | 六样工具清单、逐项检查清单、虚拟环境命令、`.gitignore` 模板 |
| 1.5 | `05-structure.html` | 推荐目录结构、每层该放/不该放什么、最小可运行项目（含运行命令） |
| 汇总 | `index.html` | 五节入口 + 技术栈全景 |

## 怎么跑

```bash
cd frontend/ch01-overview
python3 -m http.server 8082
# 打开 http://localhost:8082
```

本章全部是静态页面，**直接双击 `index.html` 也能看**，不依赖 HTTP 服务。

## 说明

- `05-structure.html` 里的「最小可运行项目」是**代码展示**，不在本仓库运行；
  真正可运行的后端在 `backend/` 目录（后续章节补齐）
- 本章页面不加载任何 JS，检查清单的勾选状态不会保存，刷新即重置
- 技术栈口径以专题 1.3 正文为准：**HTML/CSS/JS + Python(FastAPI) + MySQL**
