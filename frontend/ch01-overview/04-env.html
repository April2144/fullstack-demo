三、虚拟环境：为什么必须用

不同项目依赖的包版本可能冲突。装到全局，A 项目升级一个包，B 项目就跑不起来了。

# 创建（项目根目录执行一次）
python3 -m venv venv

# 激活
source venv/bin/activate        # macOS / Linux
venv\Scripts\activate           # Windows

# 装依赖并记录
pip install fastapi uvicorn
pip freeze > requirements.txt

# 退出
deactivate

激活成功的标志：命令行提示符前面出现 (venv)。
