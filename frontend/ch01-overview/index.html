本专题技术栈

全套只有四样东西，后续章节不再更换：

前端   HTML / CSS / JavaScript          # 无框架、无构建工具
后端   Python + FastAPI                 # 自动生成接口文档
数据库 MySQL                            # 关系型，成熟稳定
部署   Nginx + Uvicorn                  # 静态托管 + 反向代理

建议的阅读顺序

先看 1.1 把链路跑通概念，再看 1.2 弄清职责边界， 然后 1.3 理解为什么这么选，最后 1.4 / 1.5 把环境装好、把目录搭起来。 环境没装好就往下写代码，后面每一步都会卡。
