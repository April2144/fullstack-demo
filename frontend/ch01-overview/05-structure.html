第一个全栈项目结构预览

总览 请求流程 前后端职责 技术栈 环境搭建 项目结构

一、一个全栈项目由什么组成

四块内容 + 一个根目录。先把地盘划清楚，后面写代码才知道该放哪。

前端页面与交互
+
后端接口与业务
+
数据库表结构与数据
+
文档接口与部署说明

二、推荐的目录结构

分层的目的是能一眼看出某个文件属于哪一层。改需求时不用满仓库找。

my-fullstack-app/
├── frontend/                 # 前端：静态文件，直接由 Nginx 托管
│   ├── index.html
│   ├── css/
│   │   └── style.css
│   ├── js/
│   │   ├── api.js            # 所有请求集中在这里，别散落在各页面
│   │   └── main.js
│   └── data/                 # 开发期的模拟数据
│
├── backend/                  # 后端：FastAPI 应用
│   ├── main.py               # 入口：创建 app、挂路由
│   ├── routers/              # 路由层：只负责收参数、返回响应
│   ├── services/             # 业务层：真正的逻辑
│   ├── models/               # 数据模型：表结构定义
│   └── core/
│       └── config.py         # 配置：数据库连接、密钥
│
├── database/
│   ├── schema.sql            # 建表语句，可版本化
│   └── seed.sql              # 初始数据
│
├── docs/                     # 接口文档、部署说明
│
├── .env                      # 环境变量，不进 Git
├── .gitignore
├── requirements.txt
└── README.md

三、每层该放什么、不该放什么

目录 放什么 别放什么
frontend/js/api.js 所有 fetch 调用、统一的错误处理 页面渲染代码、DOM 操作
backend/routers/ 路径定义、参数声明、调用 service 复杂业务逻辑、直接写 SQL
backend/services/ 业务规则、事务、多个模型协同 HTTP 相关的东西（状态码、请求对象）
backend/models/ 表结构、字段类型、关系 业务判断、接口返回格式

四、最小可运行项目

下面这份代码不到 30 行，但已经是一条完整链路：浏览器 → FastAPI → 返回 JSON。 先跑通它，再往上加功能。

backend/main.py

from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI(title="我的第一个全栈应用")

# 开发期前后端分开跑（端口不同），必须允许跨域
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://127.0.0.1:8080"],
    allow_methods=["*"],
    allow_headers=["*"],
)

@app.get("/api/hello")
def hello():
    return {"code": 200, "message": "接口通了", "data": {"name": "全栈"}}

frontend/index.html

<!DOCTYPE html>
<html lang="zh-CN">
<body>
  <button id="btn">请求接口</button>
  <p id="out"></p>

  <script>
    document.getElementById('btn').addEventListener('click', async () => {
      const res = await fetch('http://127.0.0.1:8000/api/hello');
      const json = await res.json();
      document.getElementById('out').textContent = json.message;
    });
  </script>
</body>
</html>

运行

# 后端（项目根目录）
uvicorn backend.main:app --reload --port 8000

# 前端（另开一个终端）
cd frontend
python3 -m http.server 8080

打开 http://127.0.0.1:8080，点按钮出现「接口通了」，说明前端、后端、跨域三件事都通了。
