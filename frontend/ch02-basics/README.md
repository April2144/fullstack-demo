## 文件对照

| 笔记 | 文件 | 内容 |
|---|---|---|
| 2.1 | `01-index.html` | 语义化标签、标题层级、列表、表格、表单、图片 |
| 2.2 | `02-style.css` | 变量、盒模型、Flex 布局、间距与字号体系、响应式断点 |

| 汇总 | `index.html` | 把 2.1–2.5 串成一个可交互的小页面 |

## 怎么跑

```bash
cd frontend/ch02-basics
python3 -m http.server 8080
# 打开 http://localhost:8080
```

- `01-index.html` 可以单独打开（只看结构与样式）
- `index.html` 是汇总页，包含 2.4 / 2.5 的交互
- **`2.5 fetch` 必须走 HTTP**：直接双击打开（`file://`）时浏览器会拦截本地文件请求

## 说明

- `03-basics.js` 只往控制台打印示例，打开开发者工具 Console 就能看到每一段的结果
- 没有使用任何框架、构建工具、CDN 依赖，双击即可读源码
