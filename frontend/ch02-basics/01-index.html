三、表单

每个输入项都要有 label，并且用 for 关联到控件的 id。

四、图片与语义标签

图片必须有 alt：加载失败时显示它，读屏软件也靠它描述图片。

强调、斜体、行内代码、高亮 都是语义标签，不是"变个样子"。

标题只有 h1 到 h6 六级，h1 一个页面只用一个。 层级不要跳：有了 h2 再用 h4，读屏软件会以为中间漏了一节。

链接的三种常见写法

  • 站内跳转：回到「列表」（href="#id"）
  • 外部链接：MDN HTML 文档 —— 新窗口打开要加 target="_blank"，并且必须配 rel="noopener noreferrer"， 否则新页面能通过 window.opener 反向操作你的页面
  • 非网页协议：发邮件、 打电话

六、块级元素与行内元素

这是 CSS 布局的地基：块级独占一行、能设宽高；行内跟着文字走、宽高由内容决定。

对比项 块级（block） 行内（inline）
常见标签 div p h1~h6 ul section span a strong em code
是否独占一行 是 否，多个可以并排
width / height 是否生效 生效 不生效（设了也被忽略）
上下 margin 生效 不撑开行高，看起来像没生效

行内元素要设宽高，就把它变成 inline-block 或 block， 这是第 2.2 节 display 的用处。

七、display、伪类与定位

同样是 span，只改 display，排版行为完全不同：

block：独占一行，width 240px 生效 inline：宽 240px 被忽略，跟着文字走 inline-block：并排但能设宽高 display: none：代码里在，页面上不占位

display: none 与 visibility: hidden 的区别： 前者不占位置，后者占着位置只是看不见。

伪类：不写 class 也能选中
