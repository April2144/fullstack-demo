一、卡片网格

用 grid-template-columns: repeat(auto-fit, minmax(220px, 1fr))， 列数由容器宽度自动决定，不需要写断点。

结构

HTML 决定内容层级，布局从语义出发。

样式

CSS 负责尺寸与间距，不把布局写死在标签上。

行为

JS 只处理交互，不参与静态排版。

二、带操作按钮的列表

列表项用 Flex 一左一右：文本区 flex:1，按钮区固定宽度，不会挤压。

  • 写布局先画骨架，再填内容
  • 固定宽度用 flex:0 0 220px，别用 width

三、详情页布局

详情页常见三段：标题区 + 正文区 + 操作区。正文限制最大宽度，长文才好读。
