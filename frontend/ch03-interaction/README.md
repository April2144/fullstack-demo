# 第 3 章 · 页面开发与交互

对应笔记：`3.1 页面布局实战` / `3.2 样式与主题设计` / `3.3 表单与用户输入` / `3.4 动态交互与数据渲染` / `3.5 响应式设计与移动端适配`

## 文件对照

| 笔记 | 文件 | 内容 |
|---|---|---|
| 3.1 | `01-layout.html` | 页面骨架（页头/主体/侧栏/页脚）、水平导航、卡片网格、带操作按钮的列表、详情页布局、按钮变体、空状态与加载骨架、消息提示 |
| 3.2 | `02-theme.html` + `02-theme.css` + `02-theme.js` | CSS 变量、配色/字体/间距/圆角体系、深色模式三种写法、主题切换与防闪烁 |
| 3.3 | `03-form.html` + `03-form.js` | 12 种输入控件、表单样式、失焦与实时校验、错误提示、字符计数、密码显示、提交与数据收集 |
| 3.4 | `04-render.html` + `04-render.js` | 列表渲染、`DocumentFragment`、安全高亮、搜索防抖、筛选、排序、分页、空/加载状态 |
| 3.5 | `05-responsive.html` + `05-responsive.css` | 视口、媒体查询断点、流式布局、两栏变一栏、媒体自适应、移动端导航、触控优化、安全区域 |
| 汇总 | `index.html` | 五节入口页 |
| 数据 | `data/items.json` | 3.4 的模拟数据（20 条） |

## 怎么跑

```bash
cd frontend/ch03-interaction
python3 -m http.server 8081
# 打开 http://localhost:8081
```

- 3.1 / 3.2 / 3.3 / 3.5 都是纯静态页面，直接双击也能看
- **3.4 必须走 HTTP**：`fetch('data/items.json')` 在 `file://` 下会被浏览器拦截
- 3.2 与 `index.html` 用 localStorage 记住主题选择，刷新后保持

## 说明

- `style.css` 以第 2 章 `02-style.css` 为基线复制后追加，保证本章能**单独运行**（代价是部分样式与第 2 章重复）
- `02-theme.css` 只覆盖变量，必须放在 `style.css` 之后引入，否则会被基线变量盖回去
- 主题切换用 `html[data-theme]` 与 `prefers-color-scheme` 结合：默认跟随系统，用户手动切换后以用户选择为准
- 全程无框架、无构建工具、无 CDN 依赖
