本章示例

五节各是一个独立页面，从「文件怎么放」讲到「代码怎么发到线上」。 除 4.4 的构建脚本外，全部是原生 HTML / CSS / JavaScript。

小节 页面 看什么
4.1 项目目录结构设计 01-structure.html 四层职责、依赖方向、就近原则、三个常见反例
4.2 静态资源管理 02-assets.html 资源分类、目录约定、版本号 / 内容哈希与缓存
4.3 代码规范与模块化 03-modules/index.html ES Module 四种导入写法、运行时真实加载的三个文件
4.4 构建与压缩 04-build/04-build.html 几十行脚本实现合并 + 压缩，实测体积减少 47.8%
4.5 配置管理 05-config/05-env.html 一套配置三种环境，现场切换；密钥为什么不能放前端

怎么跑

cd frontend/ch04-tooling
python3 -m http.server 8082
# 打开 http://localhost:8082

文件说明

style.css
本章公共样式：以第 2 章样式为基线，追加导航、体积对比、模块关系、产物目录对照等组件。
03-modules/js/
4.3 的三个模块：main.js 入口、api.js 请求、utils.js 纯函数。
04-build/build.mjs
4.4 的构建脚本，零依赖。只做合并 + 去注释 + 压空白，对应构建工具最核心的两个动作。
04-build/dist/
构建产物，不要手改：每次 node build.mjs 都会整个覆盖。
05-config/config.js
4.5 的环境配置表与环境判定；env.js 只负责渲染，两者职责互不越界。
