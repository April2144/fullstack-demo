一、三个文件，各管一件事

main.js → api.js → utils.js
文件 职责 导出
js/utils.js 纯函数：格式化日期、截断文本、排序 formatDate truncate sortByDateDesc
js/api.js 所有网络请求，含统一错误处理 fetchNotes
js/main.js 页面逻辑：拿数据、处理、渲染 无（它是入口，不对外导出）

依赖是单向的：main 依赖 api 和 utils， 但 utils 谁都不依赖。反向依赖一出现，就会出现循环引用。

    三、import / export 的四种写法

    ① 命名导出 + 命名导入（最常用，一个文件可以导出多个）

    // utils.js
export function formatDate(iso) { /* ... */ }

// main.js
import { formatDate } from './utils.js';

    ② 默认导出（一个模块只有一个默认导出）

    // logger.js
export default function log(msg) { console.log(msg); }

// main.js —— 名字可以自己起
import log from './logger.js';

    ③ 全部导入成命名空间

    import * as utils from './utils.js';
utils.formatDate('2026-10-21');

    ④ 重命名（两个模块导出同名时用）

    import { formatDate as formatShort } from './utils.js';
